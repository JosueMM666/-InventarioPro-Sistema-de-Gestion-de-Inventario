# -InventarioPro-Sistema-de-Gesti-n-de-Inventario
InventarioPro aplicación de escritorio desarrollada en Python y SQLite para gestionar inventarios de forma sencilla. Permite registrar productos, controlar entradas y salidas, consultar existencias bajas, visualizar resúmenes, exportar datos a CSV y realizar copias de seguridad. Preparada para generar ejecutable para Windows mediante PyInstaller.
